## О проекте

Одностраничный сайт с презентацией услуг компании и формой обратной связи для отправки заявок.

## Реализовано

- Презентация услуг и разделы по автомобилям, мотоциклам, спецтехнике и запчастям.
- Адаптивный интерфейс.
- Отправка заявок через серверный API на Vercel.
- Интеграция с Bitrix24 CRM для работы с обращениями клиентов.

## Локальный запуск

Требуются Node.js и npm.

```bash
git clone https://github.com/Savatan/GenesisAuto.git
cd GenesisAuto
npm install
npm run dev
```

Сборка для production:

```bash
npm run build
```
