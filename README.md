# Genesis Auto

Веб-сайт компании по подбору и доставке автомобилей из Китая, Кореи и Японии.

**Демо:** https://genesis-auto-pied.vercel.app/

## О проекте

Одностраничный сайт для презентации услуг компании и получения заявок от потенциальных клиентов. Интерфейс помогает посетителю быстро понять направление работы и перейти к обращению.

## Возможности

- Презентация услуг по подбору автомобилей.
- Направления: автомобили, мотоциклы, спецтехника и запчасти.
- Адаптивный интерфейс для разных размеров экрана.
- Форма обратной связи с отправкой заявки через серверный API.
- Подготовленная основа для интеграции с CRM.

## Технологии

- Vue 3
- Vite
- JavaScript (ES modules)
- Tailwind CSS
- Vercel для публикации сайта

## Локальный запуск

Требуется установленный Node.js и npm.

```bash
git clone https://github.com/Savatan/GenesisAuto.git
cd GenesisAuto
npm install
npm run dev
```

Vite выведет локальный адрес приложения в терминале.

## Проверка production-сборки

```bash
npm run build
npm run preview
```

## Структура и конфигурация

- `src/` — исходный код интерфейса (если используется в текущей версии проекта).
- `public/` — статические ресурсы.
- `package.json` — зависимости и команды проекта.
- `vite.config.*` — настройки Vite.

Фактическая структура может меняться по мере развития проекта.

## Что демонстрирует проект

- Создание интерфейса на Vue 3.
- Сборку и запуск проекта через Vite.
- Подготовку сайта для реального бизнеса.
- Интеграцию клиентской формы с серверным API.

Проект развивается. Перед публикацией изменений проверьте работу формы обратной связи и настройки переменных окружения в среде деплоя.
