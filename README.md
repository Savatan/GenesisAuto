# Genesis Auto

Сайт компании по подбору автомобилей из Китая, Кореи и Японии.

**Демо:** https://genesis-auto-pied.vercel.app/

## Что реализовано

- Одностраничный сайт с презентацией услуг компании.
- Разделы по автомобилям, мотоциклам, спецтехнике и запчастям.
- Адаптивный интерфейс.
- Форма обратной связи для отправки заявок.
- Отправка сообщений через серверный API на Vercel.
- Интеграция с Bitrix24 CRM для работы с обращениями клиентов.

## Стек

- Vue 3
- JavaScript
- Vite
- Tailwind CSS
- Vercel API
- Bitrix24 CRM

## Запуск локально

Требуется Node.js и npm.

```bash
git clone https://github.com/Savatan/GenesisAuto.git
cd GenesisAuto
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```
