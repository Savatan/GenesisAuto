# Genesis Auto

Сайт компании по подбору автомобилей из Китая, Кореи и Японии.

[**Открыть сайт ↗**](https://genesis-auto-pied.vercel.app/)

Сайт представляет услуги компании, содержит разделы автомобилей, мотоциклов, спецтехники и запчастей. Заявки отправляются через серверный API на Vercel с интеграцией в Bitrix24 CRM.

**Стек:** Vue 3 · JavaScript · Vite · Tailwind CSS · Vercel API · Bitrix24
